# 🇪🇺 Itinerario Europa - React App

Aplicación web moderna para gestionar itinerarios de viaje con **Dark Mode**.

## ✨ Características

- 🌙 **Dark Mode** por defecto con tema púrpura
- 📱 **Responsive Design** - Móvil, tablet y desktop
- 💾 **Persistencia automática** con localStorage
- 🔍 **Búsqueda y filtros** avanzados
- 💰 **Conversión USD/COP** en tiempo real
- 📅 **Calendario dinámico**
- 📊 **Estadísticas del viaje**
- 📤 **Exportación** JSON y CSV

## 🚀 Instalación

```bash
npm install
npm run dev
```

Creado con React + Vite + Tailwind CSS
